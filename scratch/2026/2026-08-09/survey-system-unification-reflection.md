# Survey system unification — session reflection

One session took the survey layer from two divergent campaigns to one
system: absorbed dataflow-selection-enumeration with full history,
united both methodologies in the run-survey skill (updatable
systematic map; three-ledger record spine — catalog, log, queries;
claims + evidence binding; syntheses as the standard understanding
layer; shared tooling shipping with the skill), simplified
relentlessly toward one-canonical-home-per-fact, aligned terminology
with the field's canon (crosswalk in the skill's references/), ran a
two-direction adversarial audit that found twelve findings with
errors on both sides, and backfilled aarm to the standard shape.

## Principles that emerged (promoted this session)

- One canonical home per fact; derived views generated, never
  committed (AGENTS.md Conventions). The day's only data bug — a
  hand-copied 201 against the ledger's 202 — was duplication drift.
- Merge commits bypass pre-commit hooks; load-bearing guards also run
  at pre-push or CI (AGENTS.md Guards).
- Flag design deviations from explicit instructions before building;
  task-scoped process suggestions expire with the task (memory).
- Co-evolution of a spec and its instances ends with a two-direction
  independent audit (evolve skill).
- Analysis text preceding an AskUserQuestion is eclipsed by the
  dialog; deliver analysis as final turn text (memory, mid-session).

## Staged lessons (not yet earned; promote on recurrence)

- Drafter prompts that include verify-against-source self-review
  return record corrections as a byproduct — five times this session
  (venue and batch-size errors, an inverted decision rule, manuscript
  compressions). Possibly run-survey-specific; watch elsewhere.
- Batch text edits via assert-guarded replaces that write only after
  every pattern matches: prevented partial writes ~3×, but failed
  asserts abort silently mid-plan — consider a standing convention
  for the pattern (verify state after any aborted batch).
- When renaming or shortening identifiers, check for sense
  collisions ("Claim" field supporting claims; Sxx after the H-vs-S
  contrast died).
- Naming: prefer the established field term when one exists
  (updatable systematic map, Finding/grounds); keep house nouns
  short and crosswalked. Codified for surveys; may generalize.
