# Static hosting options for a ~100-page Astro site (surveyed 2026-08-22)

Site profile assumed: <100 MB build, low traffic (<10 GB/mo), apex `.com` with DNS at Cloudflare. Every item cites the primary page read; "unverified" marks secondary-only claims.

## 1. Per-option facts

**GitHub Pages** ([limits](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits), [HTTPS](https://docs.github.com/en/pages/getting-started-with-github-pages/securing-your-github-pages-site-with-https), [custom domains](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/about-custom-domains-and-github-pages)): site ≤1 GB, soft 100 GB/mo bandwidth, soft 10 builds/h (not applied to Actions deploys), 10-min deploy timeout, one user site per account, non-commercial. Custom domain: apex via A/AAAA/ALIAS, `www` via CNAME (GitHub calls `www` "most stable"); Let's Encrypt cert auto-issued after DNS check; "Enforce HTTPS" toggle; domain verification prevents takeover. Docs do not state whether `user.github.io` redirects to the custom domain — unverified. Deploy: branch, or Actions `upload-pages-artifact`/`deploy-pages` (artifact actions v4 mandatory since 2025-01-30, [changelog](https://github.blog/changelog/2024-12-05-deprecation-notice-github-pages-actions-to-require-artifacts-actions-v4-on-github-com/)). No 2025–26 Pages deprecation found in the changelog search.

**Cloudflare Workers static assets** ([billing](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/), [limits](https://developers.cloudflare.com/workers/platform/limits/), [workers.dev](https://developers.cloudflare.com/workers/configuration/routing/workers-dev/), [custom domains](https://developers.cloudflare.com/workers/configuration/routing/custom-domains/), [Pages→Workers guide](https://developers.cloudflare.com/workers/static-assets/migration-guides/migrate-from-pages/)): "Requests to static assets are free and unlimited" (the 100k req/day free cap applies only to Worker-script invocations); 20,000 files, 25 MiB each, per version. Custom Domain requires the zone on Cloudflare (already true here); apex supported; cert auto-provisioned; declared in wrangler `routes` with `custom_domain = true`. `*.workers.dev` disable-able via `workers_dev = false` (must be in config or it re-enables on next deploy). Deploy: `wrangler deploy`, Workers Builds (git), or `wrangler-action` in GitHub Actions ([CI/CD](https://developers.cloudflare.com/workers/ci-cd/)). **Pages status:** Cloudflare blog 2025-04-08: "Pages will continue to be supported, but, going forward, all of our investment… will be dedicated to improving Workers" ([blog](https://blog.cloudflare.com/full-stack-development-on-cloudflare-workers/)); docs frame migration as optional, no deprecation date published. "Maintenance mode" wording appears only in third-party posts.

**Netlify** ([pricing](https://www.netlify.com/pricing/), [credits](https://docs.netlify.com/manage/accounts-and-billing/billing/billing-for-credit-based-plans/how-credits-work/), [domains](https://docs.netlify.com/manage/domains/domains-fundamentals/understand-domains/)): credit-based since 2025-09-04 for new accounts. Free = 300 credits/mo, hard cap — when exhausted "all of your web projects… are paused" with a "Site not available" page. Production deploy 15 credits; bandwidth 20 credits/GB; 2 credits/10k requests. So 300 credits ≈ e.g. 10 deploys + 7.5 GB. Custom domains + SSL on Free. `*.netlify.app` "will always work even if you set up a custom domain"; workaround is a `_redirects` 301. (May-2026 rate increases from 10→20 credits/GB: secondary sources only — unverified.)

**Vercel Hobby** ([plan](https://vercel.com/docs/plans/hobby), [fair use](https://vercel.com/docs/limits/fair-use-guidelines), [limits](https://vercel.com/docs/limits)): free; 100 GB Fast Data Transfer/mo, 100 deployments/day, 1 concurrent build, 50 domains/project, 100 MB CLI upload. "Hobby teams are restricted to non-commercial personal use only" — ads, donations, or being paid to build the site count as commercial. Hobby cannot connect to org-owned Git repos. `*.vercel.app` cannot be removed; it can be set to redirect to the custom domain (docs/community; not a single primary statement — partly unverified).

**Object storage + CDN.** S3+CloudFront ([CloudFront PAYG](https://aws.amazon.com/cloudfront/pricing/pay-as-you-go/), [S3](https://aws.amazon.com/s3/pricing/)): CloudFront always-free 1 TB/mo out + 10M requests + free certs; S3 GETs $0.0004/1k; new accounts since 2025-07-15 get $200 credits instead of the old free tier. Net cost for this site ≈ cents/mo; effort: bucket + distribution + ACM cert + OAC + CI sync. Bunny ([CDN](https://bunny.net/pricing/), [storage](https://bunny.net/pricing/storage/)): $0.01/GB EU/NA CDN, $0.01/GB-mo storage, no request fees, **$1/mo minimum**; effort low (storage zone + pull zone + CNAME). B2 + Cloudflare ([pricing](https://www.backblaze.com/cloud-storage/pricing)): first 10 GB free, $6.95/TB-mo, free egress through Cloudflare; effort medium (bucket, Cloudflare proxy rules/Worker for index rewriting, cache rules).

**VPS + Caddy.** Hetzner CX23 €5.49/mo after the 2026-06-15 adjustment, 20 TB traffic ([price page](https://docs.hetzner.com/general/infrastructure-and-availability/price-adjustment/); IPv4 surcharge ≈€0.50 — secondary, unverified). DigitalOcean $4/mo Basic droplet, 500 GiB transfer, IPv4 included ([pricing](https://www.digitalocean.com/pricing/droplets)). Ops: OS patching, Caddy upgrades, SSH hardening, backups, single-node single-region; breaks on reboot-without-autostart, expired payment, disk full, ACME failures behind a misconfigured proxy.

**Codeberg / sourcehut / Neocities.** Codeberg Pages is mid-migration to `git-pages`; custom domains via CNAME/A + `_git-pages-repository` TXT, Let's Encrypt; deploy by webhook or Forgejo Actions; v2 server disabled for new users ([docs](https://docs.codeberg.org/codeberg-pages/using-custom-domain/)). sourcehut pages: tarball ≤1 GiB, BYO domain, auto TLS, strict CSP (no external scripts); maintainers "are expected to pay" ([limits](https://srht.site/limitations), [billing FAQ](https://man.sr.ht/billing-faq.md)). Neocities: custom domains only on Supporter $5/mo; Free 1 GB/200 GB ([plans](https://neocities.org/supporter)). All viable for a static site; none publish status histories comparable to the majors.

**Multi-host / failover.** Deploy the same `dist/` to two hosts from one workflow (e.g. `deploy-pages` + `wrangler-action`); flip via Cloudflare DNS API. TTL: proxied records are fixed "Auto" = 300 s; DNS-only records allow 60 s minimum ([TTL docs](https://developers.cloudflare.com/dns/manage-dns-records/reference/ttl/)). Cloudflare Load Balancing with health checks: official pricing page not reachable (404); secondary sources say from $5/mo, no free tier — **unverified**. Note the dependency: DNS, proxy, and Workers share one vendor; a Cloudflare edge outage takes out a Cloudflare-proxied GitHub Pages origin too, so a real hedge needs DNS-only (grey-cloud) records or a second DNS provider. "Origin-less" serving from a git mirror: no primary-source pattern found; static-asset hosts already behave as origin-less for the owner.

## 3. Reliability evidence (2025–2026)

Status-page APIs return only the last ~50 incidents, so full-year counts "could not be quantified" except where vendors publish monthly reports.

**GitHub** — monthly availability reports ([index](https://github.blog/news-insights/)): Aug-25 3, Sep 3, Oct 4, Nov 3, Dec 5, Jan-26 2, Feb 6, Mar 4, Apr 10, May 9, Jun 6, Jul 8 incidents. Pages/Actions-affecting: Feb 2 2026 (5h53m, Pages+Actions), Feb 9 (two, ~1h each, Pages+Actions), Apr 13 (1h37m Pages), Jul 9 (9h18m Actions + Pages builds), Jul 8 (7h04m), **Aug 6–7 2026 10h42m Actions+Pages** ([status](https://www.githubstatus.com/incidents/qcvjkzcs7j74)), **Aug 17 2026 7h47m** site-wide incl. Pages ([post](https://github.blog/news-insights/company-news/the-august-17-outage-and-the-work-ahead/)). Aug 2026 alone: 12 incidents, 3 critical (status API, Aug 6–23). Trend: rising frequency and multi-hour Actions outages in 2026; GitHub attributes this to capacity and is migrating to Azure.

**Cloudflare** — blog post-mortems ([tag](https://blog.cloudflare.com/tag/outage/)): Jun 12 2025; Jul 14 (1.1.1.1); Aug 21; Sep 12 (dashboard/API ~1h, edge unaffected); **Nov 18 2025** global, 11:20–14:30 UTC core, 17:06 full, all proxied traffic ([post](https://blog.cloudflare.com/18-november-2025-outage/)); **Dec 5 2025** 25 min, 28% of HTTP traffic ([post](https://blog.cloudflare.com/5-december-2025-outage/)); **Feb 20 2026** 6h07m, BYOIP customers only ([post](https://blog.cloudflare.com/cloudflare-outage-february-20-2026/)); "Code Orange: Fail Small" declared complete May 2026. Status API Aug 11–23 2026: 33 incidents, 25 minor, 1 major, 0 critical, mostly regional/Durable Objects. Severity profile: rare but global edge failures.

**Netlify** — status API Mar 27–Aug 23 2026: 46 incidents; 2 critical (May 19 latency; Aug 18 6-min 500s serving sites), 5 major, several build incidents "triggered by upstream GitHub incidents". No 2025 major serving outage found in the sources consulted.

**Vercel** — Oct 20 2025 AWS us-east-1 cascade: ~22% traffic, ~3.5 h serving, ~8.5 h control plane ([post](https://vercel.com/blog/update-regarding-vercel-service-disruption-on-october-20-2025)); status API Jun 1–Aug 23 2026: 25 incidents, 1 critical (dashboard auth), 7 major, mostly dashboard/builds/observability, one "degraded CDN" minor (Jul 2).

## 4. What the evidence supports

For this site every option is free or ≤$7/mo, so cost does not discriminate; what does is (a) GitHub's 2026 record of multi-hour Actions/Pages outages versus Cloudflare's rarer but global edge failures, (b) the fact that DNS, proxy and Workers already sit on Cloudflare, so "hedging" by adding Cloudflare hosting concentrates rather than spreads risk unless DNS-only records are kept as a flip path, (c) Netlify's hard credit cap and Vercel's commercial clause make both conditional free tiers, and (d) the only hosts with no always-on default hostname are the object-storage/VPS routes. Unverified items: Cloudflare Load Balancing price, Hetzner IPv4 surcharge, Netlify May-2026 credit rates, GitHub default-hostname redirect behaviour.
