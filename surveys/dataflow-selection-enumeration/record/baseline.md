# Initial mapping baseline

This file records the compact, durable outcome of the first mapping campaign.
The audited log retains the execution evidence (the baseline's
frozen result sets were retired from the record on 2026-08-09); Git
history retains the superseded chronological closure narrative.

## Snapshot

- **Coverage date:** 2026-08-04
- **Study type:** systematic mapping study with backward and forward
  snowballing
- **Catalog entries:** 897
- **Deep-read works:** 201
- **Audited database-query rows:** 318
- **Audited backward or forward citation chases:** 245
- **Screened record occurrences:** 35,720 after excluding repeated independent
  adjudication passes; this is not a unique-work count
- **Claim-evidence rows:** 83

The first map was declared closed only after every exploratory addition was
reconciled, all critical works were read and chased in both directions, two
prospectively frozen no-add rounds completed, and separate audit passes checked
the final records and exclusions. Closure was relative to the recorded sources,
queries, rankings, and date. It was never a claim of worldwide completeness.

## Durable outcome

The original broad novelty thesis did not survive. Existing work already
supplies guarded symbolic partitions, projected and disjoint model
enumeration, demand-sensitive and choice-fingerprint search, decision
structures, observer-equivalence partitions, exact geometric and neural-region
enumeration, and observer-preserving reductions.

The retained contribution is a survey taxonomy and formal synthesis. It uses a
requested-root-relative selection observer as a running object for comparing
structural non-observation, logical don't-care, projection, extensional
coalescing, abstraction, and search reduction. The formal correspondence is an
organizing derivation, not a claim to a new generic enumeration paradigm.

## Evidence locations

- `log.tsv` records every audited query or citation chase.
- `catalog.tsv` records the current disposition of discovered works.
- `sources/` anchors technical extraction in primary works.
- `syntheses/` records the current cross-paper interpretation.
- `evidence-matrix.tsv` connects manuscript claims to source-note anchors.

## Reopening rule

The baseline is superseded for current-status purposes as soon as a later work,
a newly exposed vocabulary cluster, or a changed primary result could alter the
taxonomy, comparison boundary, formal synthesis, or manuscript. Such a finding
starts an update batch under the README's To update procedure; it
does not rewrite this
baseline.
