# giua2005state — Exact marking estimation with silent transitions

- **Status:** deep-read; exact inverse-observation representation
- **Primary source:** https://doi.org/10.1007/s10626-005-5239-4
- **Version read:** author-hosted journal full text
- **Bibliography key:** `giua2005state`

## Evidence locations

- Problem and construction: for a contact-free nondeterministic lambda-free
  labeled Petri net, a fixed-structure linear system represents all markings
  consistent with the received label word.
- Representation result: the number and dimensions of the linear constraints
  are independent of the observation length; integer solutions recover the
  complete consistency set under the paper's assumptions.

## Relationship and evidence limit

This is the immediate linear-estimator predecessor to the later minimal-
explanation basis representation. It exactly represents a current-marking
inverse set, not a partition of all program inputs or a typed residual.
