# tobinhochstadt2012contracts — Higher-order symbolic values from contracts

- **Status:** deep-read; foundational higher-order symbolic execution
- **Primary source:** https://doi.org/10.1145/2384616.2384655
- **Version read:** primary OOPSLA full text
- **Bibliography key:** `tobinhochstadt2012contracts`

## Evidence locations

- Symbolic semantics: contracts describe unknown functional behavior and act
  as symbolic higher-order values during modular execution.
- Guarantee: the symbolic semantics soundly overapproximates concrete program
  behavior for contract verification.

## Relationship and evidence limit

This establishes open higher-order symbolic inputs before the relatively
complete counterexample work. It is a behavioral overapproximation, not a
duplicate-free exact observer-fiber enumeration.
