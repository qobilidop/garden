## Evidence locations

- Section 3: if one abstract shape's concretizations are included in another's,
  rule applications from the larger shape cover those from the smaller shape,
  so the subsumed state can be discarded.
- Evaluation: subsumption substantially reduces abstract graph state spaces,
  running time, and memory on the reported grammars.

## Relationship and evidence limit

This generalizes the state-set-inclusion omission mechanism beyond symbolic
heaps. The neighborhood abstraction over-approximates possibly infinite graph
state spaces; it neither partitions concrete inputs exactly nor emits a
residual per observer fiber.
