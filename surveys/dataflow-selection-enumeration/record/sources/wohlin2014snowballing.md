# wohlin2014snowballing — backward and forward snowballing guidance

- **Status:** methodology source
- **Primary source:** https://doi.org/10.1145/2601248.2601268
- **Bibliography key:** `wohlin2014snowballing`

## Evidence used

The paper presents guidelines for systematic literature studies using
backward and forward snowballing. The manuscript uses it only to justify
recording the two directions separately around a bounded start set.

## Evidence locations

- Snowballing procedure: iterative backward-reference and forward-citation
  screening.
- Reporting discussion: explicit start set, iterations, inclusion decisions,
  and reproducibility qualifications.
