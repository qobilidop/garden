# gao2020noevent — State estimation without event observation

- **Status:** screened; alternate timed-observer comparator
- **Primary source:** https://doi.org/10.1109/ETFA46521.2020.9211942
- **Version read:** primary conference full text
- **Bibliography key:** `gao2020noevent`

## Evidence locations

- Region-observer construction: state measurements without event observations
  induce sets of possible locations and clock regions; the region abstraction
  is used to compute the exact state estimate under the stated timed-automaton
  assumptions.

## Relationship and evidence limit

This inverts a sparse state observer over timed automata. It does not enumerate
the caller-input preimages or residual values of a requested dataflow result.
