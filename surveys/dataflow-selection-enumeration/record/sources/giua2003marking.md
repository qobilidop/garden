# Marking estimation under partial observation

## Evidence

### Evidence locations

- Estimator: recursively characterize every marking consistent with an
  observed transition-label word, including nondeterministic equal labels.
- Representation: use a fixed-structure linear system whose form is independent
  of the observation-word length.

## Bearing on RQs

This is an exact inverse-consistency set for a requested event observation and
is exceptionally close semantically.

## Evidence limits

- It estimates reachable Petri-net markings after a word, not caller inputs of
  a pure dataflow function, and has no typed residual program value.
