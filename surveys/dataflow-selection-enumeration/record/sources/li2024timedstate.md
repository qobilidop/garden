# li2024timedstate — Timed marking estimation from observations

- **Status:** screened; timed partial-observation estimator
- **Primary source:** https://doi.org/10.1016/j.ins.2023.119922
- **Version read:** publisher abstract and section preview
- **Bibliography key:** `li2024timedstate`

## Evidence locations

- Publisher preview: an observed modified state class graph constructs an
  online partial state space from the logic-label component of a time-label
  sequence and estimates the timed states consistent with that observation.

## Relationship and evidence limit

This extends exact inverse-observation state estimation to labeled time Petri
nets with unobservable transitions. Detailed completeness and complexity
claims are not imported from the partial preview.
