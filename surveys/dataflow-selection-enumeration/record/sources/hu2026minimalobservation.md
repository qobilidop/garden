# hu2026minimalobservation — Minimal event observation for supervision

- **Status:** screened; minimal-observable-alphabet boundary
- **Primary source:** https://doi.org/10.3390/MATH14061058
- **Version read:** publisher abstract and method statement
- **Bibliography key:** `hu2026minimalobservation`

## Evidence locations

- Objective: minimize the event alphabet that must remain observable while
  preserving the controlled behavior of a reference supervisor.
- Method: a mixed-integer linear program selects observable events and an
  executable supervisor is constructed from the solution.
- Guarantee: the reduced-observation supervisor retains control equivalence
  with the supremal supervisor under the stated model.

## Relationship and evidence limit

The work gives an optimization and preservation theorem for the observation
domain itself. It does not enumerate all observation outcomes, inverse regions
over program inputs, or typed residual computations.
