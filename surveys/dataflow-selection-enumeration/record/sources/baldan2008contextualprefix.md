## Evidence locations

- Sections 1--2 explain why consume/produce-loop encodings of read arcs impose
  false order between concurrent readers. Contextual nets model read-only
  access directly, but asymmetric conflict means that one event can have
  several causal histories.
- Proposition 1 proves the full contextual unfolding complete for coverability:
  a marking is coverable exactly when some concurrent set of unfolding
  conditions maps to it.
- Definitions 13--16 enrich prefix events with histories and define cut-offs on
  enriched events. The history is essential: using only an event's minimal
  history can terminate with a finite but incomplete prefix.
- Theorem 1 proves the cut-off-free truncation complete: every reachable
  marking is generated by a finite configuration in the truncation. Theorem 2
  proves that an enriched prefix without local cut-offs is finite for a finite
  n-bounded contextual net.
- Section 4 gives the constructive algorithm. Lemma 3 maintains absence of
  local cut-offs, and Theorem 3 proves termination and completeness for finite
  n-bounded nets. The presentation assumes semi-weighted contextual nets;
  extending to general weighted contextual nets is described as technically,
  rather than conceptually, harder.
- Section 4 also exhibits an exponential separation from replacing read arcs
  by consume/produce loops. The conclusion notes the cost of tracking histories
  and asymmetric conflict and describes the implementation and refined
  adequate-order complexity questions as unfinished.

## Relationship and evidence limit

This changes both the Petri-net model and the nonredundancy mechanism: exact
finite prefixes preserve concurrent read access by distinguishing only the
causal histories needed for completeness. The construction represents all
reachable net markings, not outcomes at a requested pure-program site. Its
history annotations are not caller-input inverse fibers and do not contain the
program's typed residual value.
