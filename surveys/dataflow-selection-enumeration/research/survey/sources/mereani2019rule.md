# mereani2019rule — Exact and Approximate Rule Extraction

- **Status:** deep-read; exact finite Boolean observer comparator
- **Primary source:** https://doi.org/10.5220/0008362904240433
- **Version read:** institutional-repository accepted PDF, pp. 424--433
- **Bibliography key:** `mereani2019rule`

## Evidence locations

- Abstract and Section 3.4: a Boolean-input, Boolean-output classifier is a
  Boolean function and can be evaluated on every input combination.
- Sections 3.4 and 4.1: the 16-feature classifier is represented exactly by its
  truth table and minimized Boolean rules.
- Section 4.2 and conclusion: the 34-feature route samples smaller feature sets
  and is approximate; reported accuracy is empirical.

## Relationship and evidence limit

The small-domain route is an extensional exact finite observer construction and
another neural-output comparator. It retains no hidden activation event and has
exponential truth-table cost. The larger-domain route cannot support an exact
partition claim.
