# oh2013portactor — Port-based mixed actor model

- **Status:** screened; heterogeneous actor-model boundary
- **Primary source:** https://doi.org/10.1007/S11265-012-0682-6
- **Version read:** publisher abstract and article metadata
- **Bibliography key:** `oh2013portactor`

## Evidence locations

- Abstract: the port-based actor model is a transition path from legacy code to
  decidable dataflow while retaining dynamic behavior.
- Abstract: each port independently follows Kahn-process-network or decidable-
  dataflow semantics, with port groups expressing related KPN ports.
- Abstract: the combination retains static analyses including deadlock
  detection and buffer-memory sizing under the model's restrictions.

## Relationship and evidence limit

This is a per-port heterogeneous model-of-computation boundary. It addresses
analyzability and implementation, not exact sparse observation images, inverse
input fibers, or residual computation construction.
