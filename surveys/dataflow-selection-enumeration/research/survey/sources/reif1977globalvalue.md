# reif1977globalvalue — Global symbolic value graph

- **Status:** screened; compact inter-block symbolic-value representation
- **Primary source:** https://doi.org/10.1145/512950.512961
- **Version read:** primary abstract and author publication record
- **Bibliography key:** `reif1977globalvalue`

## Evidence locations

- Construction: the global value graph compactly represents both general
  symbolic expression values and the flow of those values through an arbitrary
  control-flow graph.
- Scope: the construction targets global flow analysis and obtains results as
  strong as the compared iterative and direct algorithms at lower stated time
  cost.

## Relationship and evidence limit

This is an early graph-native symbolic-value sharing precedent. It represents
global dataflow facts rather than partitioning caller inputs by a requested
internal event observer.
