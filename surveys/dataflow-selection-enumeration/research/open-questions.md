# Open research questions

- **Q01 (answered):** A sparse selection observation is not new merely as an
  object: it can be encoded as a projected model or event configuration. The
  remaining question is whether its graph-compositional characterization is
  new and consequential.
- **Q02 (provisional):** Use a finite typed term graph to make sharing explicit;
  explain dataflow graphs and combinational circuits as instances.
- **Q03 (answered):** “Demand” is not lazy execution here. Define an
  instrumented result-observation judgment over an eager pure value semantics.
- **Q04:** Must all primitive operators be total? If not, which observations from
  inactive alternatives remain semantically relevant?
- **Q05:** Which observer language and validation task justify retaining
  active equal-valued selections?
- **Q06:** Which solver guarantees are necessary for exactness and termination?
- **Q07 (provisional):** Describe the semantic construction as symbolic
  evaluation of a selective term graph and the solver baseline as projected
  enumeration; do not erase the distinction.
- **Q08:** Which complexity parameters reveal genuine savings beyond the
  unavoidable output size?
- **Q09:** Is the general theory strong enough for PLDI, or principally a CAV
  method whose value depends on implementation and evaluation?
- **Q10:** Is selection observation the least congruence refining value
  semantics for an explicit structural observer, or does a counterexample
  defeat that universal property?
- **Q11:** Can summaries hide internal non-observed values while composing
  exactly across graph substitution, shared consumers, contextual calls, and
  finite iteration?
