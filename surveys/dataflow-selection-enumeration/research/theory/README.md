# Theory workspace

These files hold the current formal model, proof obligations, counterexamples,
and complexity derivations. They are not manuscript prose.

- \`model.md\` defines finite selective term graphs and the theory boundary.
- \`semantics.md\` defines eager values, result observation, and exact fibers.
- \`enumeration.md\` gives concolic fiber generation, full-fiber blocking, and
  the projected-AllSMT reduction.
- \`composition.md\` defines demand-parametric component summaries and exact
  composition.
- \`complexity.md\` records size parameters, upper and lower bounds, and
  complexity caveats.
- \`counterexamples.md\` preserves small examples that falsify tempting claims.
