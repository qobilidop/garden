# Guidelines for Snowballing in Systematic Literature Studies and a Replication in Software Engineering

## Evidence

The abstract and public method summary present backward reference screening and
forward citation screening as complementary snowballing directions in a
systematic literature study, with an explicit start set and iterations.

## Bearing on RQs

This work informs discovery procedure rather than the technical RQs. It
supports keeping backward and forward events distinct and disclosing defective
directions; it does not establish completeness merely because both directions
were attempted.

## Evidence limits

Read at abstract and public-summary depth. The manuscript uses it only for the
high-level snowballing design, not for a detailed claim about stopping rules or
coverage.
